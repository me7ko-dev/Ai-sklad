# Гласов склад

Приложение за малки магазини: наличностите се водят с глас от телефона.
Планът по фази е в [docs/PLAN.md](docs/PLAN.md).

Не е нужно да пишете код. По-долу е описано как да пуснете приложението
така, че да се отваря на телефона. Отнема около 30 минути.

## Какво може

- **Глас:** натискате големия зелен бутон и казвате „продадох три хляба и две олиа“ или
  „дойде доставка: 20 кашона вода“. Приложението показва какво е разбрало, пита, ако не е
  сигурно („Олио 1 л или 2 л?“), и записва чак след „Да, запиши“.
- **Склад:** всички продукти с цени; това, което свършва, е червено и най-горе.
- **Поръчка:** готов списък по доставчици за изпращане по Viber, SMS или имейл,
  с телефона и имейла на всеки доставчик.
- **История:** оборот в евро, какво е продадено и доставено днес и тази седмица;
  грешен запис се отменя.
- **Без интернет:** записите се пазят на телефона и се изпращат сами, когато връзката се върне.

## Стъпка 1: База данни (Supabase)

1. Отворете https://supabase.com и натиснете **Start your project**. Влезте с GitHub акаунта си.
2. Натиснете **New project**.
   - **Name:** `glasov-sklad`
   - **Database Password:** натиснете **Generate a password** и я запишете някъде.
   - **Region:** изберете **Central EU (Frankfurt)** — най-близо до България.
   - Ако има отметка **Enable Data API**, оставете я включена.
   - Натиснете **Create new project** и изчакайте около минута.
3. От лявото меню отворете **SQL Editor** → **New query**.
4. Отворете файла [`supabase/schema.sql`](supabase/schema.sql) в GitHub, копирайте целия текст,
   поставете го в SQL Editor и натиснете **Run**. Трябва да пише *Success*.
5. (По желание) Направете същото с [`supabase/seed.sql`](supabase/seed.sql) — добавя 12 примерни
   продукта (хляб, олио, вода…), за да има с какво да пробвате. Можете да ги изтриете после.
6. Вземете двете стойности, които ще трябват след малко:
   - **Project Settings** (зъбчатото колело долу вляво) → **Data API** → копирайте **Project URL**
     (изглежда като `https://abcdefgh.supabase.co`).
   - **Project Settings** → **API Keys** → в частта **Secret keys** натиснете иконата на око
     и копирайте ключа (започва с `sb_secret_`). Ако виждате само стари ключове,
     използвайте **service_role**.

   ⚠️ Тайният ключ дава пълен достъп до базата. Не го пращайте на никого и не го
   поставяйте никъде освен във Vercel.

## Стъпка 2: Ключове за гласа (OpenAI и Anthropic)

Гласът ползва две платени услуги. Плаща се според употребата, с предварително заредени пари.

**OpenAI** (превръща гласа в текст):
1. Отворете https://platform.openai.com и направете акаунт.
2. **Settings → Billing → Add payment details** и заредете $5.
3. **API keys → Create new secret key** → име `glasov-sklad` → копирайте ключа (започва с `sk-`).

**Anthropic** (Claude разбира какво е казано):
1. Отворете https://console.anthropic.com и направете акаунт.
2. **Settings → Billing** и заредете $5.
3. **Settings → API keys → Create Key** → име `glasov-sklad` → копирайте ключа (започва с `sk-ant-`).

Ключовете се виждат само веднъж. Не ги пращайте на никого — поставят се само във Vercel.

**Колко струва приблизително** (при около 50 гласови записа на ден):
- OpenAI: под 0,1 цент на запис → около $1–2 на месец.
- Claude (по подразбиране Claude Opus 5, най-точният): около 2 цента на запис → около $30 на месец.
  Ако искате по-евтино, добавете във Vercel `ANTHROPIC_MODEL` = `claude-sonnet-5`
  (около $10–12 на месец, малко по-малко точен).
- В двата сайта можете да сложите месечен лимит, за да няма изненади.

## Стъпка 3: Качване в интернет (Vercel)

1. Отворете https://vercel.com и натиснете **Sign Up** → **Continue with GitHub**.
2. Натиснете **Add New…** → **Project** → до репото **Ai-sklad** натиснете **Import**.
   (Ако не го виждате, натиснете **Adjust GitHub App Permissions** и дайте достъп до него.)
3. Отворете **Environment Variables** и добавете редовете (Key → Value):

   | Key | Value |
   | --- | --- |
   | `SUPABASE_URL` | Project URL от Supabase |
   | `SUPABASE_SECRET_KEY` | тайният ключ от Supabase |
   | `APP_PIN` | ПИН код за влизане, поне 6 цифри, напр. `482915` |
   | `OPENAI_API_KEY` | ключът от OpenAI |
   | `ANTHROPIC_API_KEY` | ключът от Anthropic |
   | `SHOP_NAME` | (по желание) името на магазина, напр. `Магазин Здравец` |

   Без двата ключа за глас всичко останало работи — само гласът ще каже, че не е настроен.

4. Натиснете **Deploy** и изчакайте 1–2 минути.
5. Ще получите адрес като `https://ai-sklad.vercel.app`. Това е вашето приложение.

Ако някога промените настройките във Vercel: **Deployments** → трите точки до най-горния
ред → **Redeploy**, за да влязат в сила.

> Безплатният план на Vercel (Hobby) е за лична и некомерсиална употреба. За проба е наред.
> Когато магазинът започне да го ползва истински, трябва да минем на платения план
> (Pro) или на друг хостинг — ще решим заедно.

## Стъпка 4: На телефона

1. Отворете адреса от Vercel в **Chrome** (Android) или **Safari** (iPhone).
2. Въведете ПИН кода.
3. Инсталирайте като приложение:
   - **Android / Chrome:** менюто с трите точки → **Добавяне към началния екран** → **Инсталиране**.
   - **iPhone / Safari:** бутонът за споделяне (квадрат със стрелка) → **Добави към начален екран**.
4. На началния екран се появява зелена икона **Склад**.
5. Първия път, когато натиснете микрофона, телефонът ще пита за достъп — натиснете **Разреши**.

## Как се говори

- „Продадох три хляба и две бири.“
- „Дойде доставка: двайсет кашона вода и десет пакета захар.“
- „Имам точно пет олиа от два литра.“ (корекция — записва точното число)
- „Продадох кило и половина сирене.“

Съвети:
- За кашони: в продукта попълнете „В един кашон/стек има“, тогава „3 кашона вода“ става 18 бутилки.
- Ако хората наричат продукт различно (напр. „слънчогледово“ за олиото), добавете го в „Други имена“.
- Винаги проверете какво е разбрано, преди да натиснете „Да, запиши“. Грешка се отменя от „История“.

## Цени и оборот

В екрана на всеки продукт → „Промени продукта“ → **Продажна цена в евро**. Всяка продажба
запомня цената в момента, така че старият оборот не се променя, ако после смените цената.
В „История“ най-горе е оборотът за деня или седмицата. Продажби на продукти без цена
не влизат в оборота — приложението казва кои са.

## Доставчици

„Поръчка“ → **Доставчици**: попълнете телефон и имейл. Тогава в поръчката има бутони
„Изпрати по SMS“, „Изпрати по имейл“ (направо до доставчика) и „Обади се“.
Бутонът „Изпрати по Viber“ отваря Viber и там избирате на кого да го пратите.
Ако смените името на доставчик, то се сменя и във всичките му продукти.

## Без интернет

- Отворете приложението поне веднъж с интернет — тогава телефонът запазва списъка с продукти.
- Когато няма връзка, приложението само показва екран **„Няма интернет“**: изберете продукт,
  „Продадох“ / „Доставка“ / „Преброих“ и **„Запиши на телефона“**.
- Отгоре пише колко записа чакат. Щом интернетът се върне, те се изпращат сами
  (с часа, в който са направени) и излиза „✓ Изпратени“.
- Гласът не работи без интернет — трябва му връзка до OpenAI и Claude.
- Ако интернетът изчезне точно след „Да, запиши“, записът също остава на телефона.
- Не изтривайте данните на браузъра, докато има чакащи записи.

## Ако нещо не работи

| Съобщение | Какво да направите |
| --- | --- |
| „Приложението още не е настроено“ | Липсва някоя настройка от Стъпка 3.3. Добавете я и направете Redeploy. |
| „Базата данни не е подготвена или е от стара версия“ | Пуснете `supabase/schema.sql` в SQL Editor (Стъпка 1.4). |
| „Приложението няма достъп до базата“ | Проверете дали `SUPABASE_SECRET_KEY` е тайният ключ, а не публичният. |
| „Грешен ПИН“ | ПИН-ът е този в `APP_PIN` във Vercel. |
| „Липсва OPENAI_API_KEY“ или „ANTHROPIC_API_KEY“ | Добавете ключа от Стъпка 2 във Vercel и направете Redeploy. |
| „… не е валиден“ / „няма заредени пари“ | Проверете ключа и баланса в сайта на OpenAI или Anthropic. |
| „Няма достъп до микрофона“ | Настройки на телефона → приложението/браузъра → Микрофон → Разреши. |
| „N записа чакат интернет“ не изчезва | Проверете интернета. Ако пише и „не можаха да се запишат“ — продуктът е бил изтрит междувременно; запишете ръчно. |

**Обновяване на базата:** при всяка нова версия на приложението пуснете `schema.sql` отново
(SQL Editor → New query → поставете → Run). Безопасно е — само добавя новото и не губи данни.
Ако не го направите, приложението ще каже „Базата данни не е подготвена или е от стара версия“.

## За програмисти

Next.js 16 (App Router, Server Actions) + Supabase (Postgres). Всички заявки към базата
минават през сървъра с тайния ключ; в Supabase е включен RLS без правила, така че публичният
ключ няма достъп. Наличността и историята се обновяват атомарно от функциите в
`supabase/schema.sql` (`record_movement`, `record_movements`, `undo_movement`).

Гласът: `POST /api/glas` (`src/app/api/glas/route.ts`) приема аудио или текст → OpenAI
транскрипция (`src/lib/transcribe.ts`) → Claude със structured outputs
(`src/lib/understand.ts`, модел `claude-opus-5`, effort `low`, server-side fallbacks) →
отговорът се проверява срещу каталога и се връща за потвърждение. Записът става чак след
потвърждение (`saveVoiceAction`).

Без интернет: `public/sw.js` пази `/bez-internet` и файловете ѝ; записите се трупат в
localStorage (`src/lib/offline-queue.ts`) и се изпращат към `POST /api/sync`. Всеки запис има
`client_id` (уникален в `stock_movements`), така че повторно изпращане не дублира.

```bash
cp .env.example .env.local   # попълнете стойностите
npm install
npm run dev                  # http://localhost:3000
npm test                     # автоматични тестове
npm run lint && npm run typecheck
```
