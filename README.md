# Гласов склад

Приложение за малки магазини: наличностите се водят с глас от телефона.
Планът по фази е в [docs/PLAN.md](docs/PLAN.md).

Не е нужно да пишете код. По-долу е описано как да пуснете приложението
така, че да се отваря на телефона. Отнема около 20 минути и е безплатно.

## Стъпка 1: База данни (Supabase)

1. Отворете https://supabase.com и натиснете **Start your project**. Влезте с GitHub акаунта си.
2. Натиснете **New project**.
   - **Name:** `glasov-sklad`
   - **Database Password:** натиснете **Generate a password** и я запишете някъде.
   - **Region:** изберете **Central EU (Frankfurt)** — най-близо до България.
   - Ако има отметка **Enable Data API**, оставете я включена.
   - Натиснете **Create new project** и изчакайте около минута.
3. От лявото меню отворете **SQL Editor** → **New query**.
4. Отворете файла [`supabase/schema.sql`](supabase/schema.sql) в GitHub, копирайте целия текст,
   поставете го в SQL Editor и натиснете **Run**. Трябва да пише *Success*.
5. (По желание) Направете същото с [`supabase/seed.sql`](supabase/seed.sql) — добавя 12 примерни
   продукта (хляб, олио, вода…), за да има с какво да пробвате. Можете да ги изтриете после.
6. Вземете двете стойности, които ще трябват след малко:
   - **Project Settings** (зъбчатото колело долу вляво) → **Data API** → копирайте **Project URL**
     (изглежда като `https://abcdefgh.supabase.co`).
   - **Project Settings** → **API Keys** → в частта **Secret keys** натиснете иконата на око
     и копирайте ключа (започва с `sb_secret_`). Ако виждате само стари ключове,
     използвайте **service_role**.

   ⚠️ Тайният ключ дава пълен достъп до базата. Не го пращайте на никого и не го
   поставяйте никъде освен във Vercel.

## Стъпка 2: Качване в интернет (Vercel)

1. Отворете https://vercel.com и натиснете **Sign Up** → **Continue with GitHub**.
2. Натиснете **Add New…** → **Project** → до репото **Ai-sklad** натиснете **Import**.
   (Ако не го виждате, натиснете **Adjust GitHub App Permissions** и дайте достъп до него.)
3. Отворете **Environment Variables** и добавете три реда (Key → Value):

   | Key | Value |
   | --- | --- |
   | `SUPABASE_URL` | Project URL от Supabase |
   | `SUPABASE_SECRET_KEY` | тайният ключ от Supabase |
   | `APP_PIN` | ПИН код за влизане, поне 6 цифри, напр. `482915` |

4. Натиснете **Deploy** и изчакайте 1–2 минути.
5. Ще получите адрес като `https://ai-sklad.vercel.app`. Това е вашето приложение.

Ако някога промените настройките във Vercel: **Deployments** → трите точки до най-горния
ред → **Redeploy**, за да влязат в сила.

> Безплатният план на Vercel (Hobby) е за лична и некомерсиална употреба. За проба е наред.
> Когато магазинът започне да го ползва истински, трябва да минем на платения план
> (Pro) или на друг хостинг — ще решим заедно.

## Стъпка 3: На телефона

1. Отворете адреса от Vercel в **Chrome** (Android) или **Safari** (iPhone).
2. Въведете ПИН кода.
3. Инсталирайте като приложение:
   - **Android / Chrome:** менюто с трите точки → **Добавяне към началния екран** → **Инсталиране**.
   - **iPhone / Safari:** бутонът за споделяне (квадрат със стрелка) → **Добави към начален екран**.
4. На началния екран се появява зелена икона **Склад**.

## Ако нещо не работи

| Съобщение | Какво да направите |
| --- | --- |
| „Приложението още не е настроено“ | Липсва някоя настройка от Стъпка 2.3. Добавете я и направете Redeploy. |
| „Базата данни още не е подготвена“ | Пуснете `supabase/schema.sql` в SQL Editor (Стъпка 1.4). |
| „Приложението няма достъп до базата“ | Проверете дали `SUPABASE_SECRET_KEY` е тайният ключ, а не публичният. |
| „Грешен ПИН“ | ПИН-ът е този в `APP_PIN` във Vercel. |

## За програмисти

Next.js 16 (App Router, Server Actions) + Supabase (Postgres). Всички заявки към базата
минават през сървъра с тайния ключ; в Supabase е включен RLS без правила, така че публичният
ключ няма достъп. Наличността и историята се обновяват атомарно от функцията
`record_movement` в `supabase/schema.sql`.

```bash
cp .env.example .env.local   # попълнете стойностите
npm install
npm run dev                  # http://localhost:3000
```
